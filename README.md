# 番茄年报 · focus.today

番茄钟 + 年度专注热力图。每完成一个番茄攒一格，年底收获一张 GitHub 式年度专注热力图和一排成就徽章。

- **计时必须准**：时间戳基准（`endsAt - Date.now()`），`setInterval` 只管重画——切后台、锁屏、合盖再回来，时间都不漂移，睡过头按计划到点入账
- **数据是你的**：全部存本机 localStorage（`focus.v1.*`），无账号无后端，随时导出/导入 JSON
- **手写热力图**：53×7 格子、周一开始、五档复古绿，无图表库无日期库
- **10 枚成就徽章**：纯函数判定，解锁弹纸片 toast
- **零音频文件**：铃声用 Web Audio 振荡器合成（专注三音上行 / 休息两音下行）

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # vitest：按日聚合 / 连击 / 徽章 / 放弃规则（跨午夜、跨年、周一开头）
npm run build    # tsc --noEmit && vite build → dist/
```

纯静态站点，`dist/` 可直接部署到 Vercel / Cloudflare Pages。

## 上线前人工验收

M1 的"锁屏测试"是整个项目的技术验收核心：开始一个 25 分钟专注 → 锁屏 10 分钟 → 解锁后剩余时间正确、若已到点则正常入账。这是时间戳方案正确性的证明。
